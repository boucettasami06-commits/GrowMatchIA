# Photos Budgemy

Photos libres (Wikimedia Commons : CC0, domaine public, CC BY, CC BY-SA) pour les carrousels TikTok de Budgemy.
`manifest.json` liste chaque photo avec son auteur, sa licence et sa source. Les photos sous CC BY / CC BY-SA doivent être créditées.
Pour en ajouter : modifier `queries.json` et pousser ; le workflow télécharge les nouvelles photos.
